# WASM / GitHub Pages

The browser build ships with **quantum mode** (RustQIP) enabled by default.

**RustQIP** runs the same circuit presets as desktop. Probabilities are cross-checked against Qiskit Aer in CI (`rustqip_qiskit_parity`). Switch modes in-game with **CLASSIC** / **RUSTQIP** (Qiskit needs a local Python install — it does not run in a tab).

---

## Build locally

```bash
cargo install wasm-bindgen-cli   # once
./scripts/build_wasm.sh
```

Serve `docs/` with any static server:

```bash
python3 -m http.server 8080 --directory docs
# open http://localhost:8080/
```

Requires ~3 GiB free disk for the release WASM build. Use `./scripts/clean_build.sh` if needed.

## GitHub Pages

Push to `main` triggers `.github/workflows/pages.yml`:

1. `cargo build` wasm32 release (~11 min on CI)
2. `wasm-bindgen` → `docs/wasm/`
3. Deploy `docs/` folder

**Requirements:**

- Repository must be **public** (free plan) or GitHub Pro (private Pages).
- Settings → Pages → source: **GitHub Actions**.

Live URL: `https://thepriben.github.io/quantum-tetris/`

**Qiskit Aer** needs Python and does not run in the browser. **RustQIP** is the default simulator locally and on GitHub Pages.

## Randomness on WASM

`.cargo/config.toml` sets `getrandom_backend="wasm_js"` for the wasm32 target.
