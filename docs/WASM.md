# WASM / GitHub Pages

Run **Quantum Tetris** in the browser. The WASM build uses the **classic** backend only (uniform random — no Python).

---

## Build locally

```bash
cargo install wasm-bindgen-cli   # once
./scripts/build_wasm.sh
```

Serve `docs/` with any static server:

```bash
python3 -m http.server 8080 --directory docs
# open http://localhost:8080/play.html
```

Requires ~3 GiB free disk for the release WASM build. Use `./scripts/clean_build.sh` if needed.

---

```
docs/

  wasm/           generated by build_wasm.sh (gitignored until deploy)
```

## GitHub Pages

Push to `main` triggers `.github/workflows/pages.yml`:

1. `cargo build` wasm32 release (~11 min on CI)
2. `wasm-bindgen` → `docs/wasm/`
3. Deploy `docs/` folder

**Requirements:**

- Repository must be **public** (free plan) or GitHub Pro (private Pages).
- Settings → Pages → source: **GitHub Actions**.

Live URL (once deployed): `https://<user>.github.io/quantum-town-la/play.html`

**Qiskit does not run in the browser.** The web build is classic mode only. Qiskit is tested in the separate CI job `quantum-qiskit`.

---

## Randomness on WASM

`.cargo/config.toml` sets `getrandom_backend="wasm_js"` for the wasm32 target.
