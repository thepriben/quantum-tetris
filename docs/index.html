Quantum Tetris

Neon arcade Tetris where every piece is picked by a quantum circuit. The browser game runs in quantum mode by default (Born-rule simulator, Qiskit-matched). Switch to classic with the in-game button.

LRMOVE
^ROTATE
vFASTER
SpDROP

Play in browser

Local classic: cargo run -p quantum-tetris

Local Qiskit Aer: QUANTUM_MODE=qiskit cargo run -p quantum-tetris
