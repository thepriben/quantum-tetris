Quantum Sub: LA

Pilote un sous-marin, collecte 3 cellules, sors par le portail sud. Flèches + Espace. Chaque action passe par un mini-circuit ; les bits mesurés pilotent le jeu.

Jouer dans le navigateur Mode QIP

Local (Rust) :

git clone https://github.com/thepriben/quantum-town-la.git
cd quantum-town-la
cp .env.example .env
cargo run -p quantum-town-la
